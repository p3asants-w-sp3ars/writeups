# MeowSim: Schrodinger Edition

## Summary

Это Android reverse-задача: приложение выдаёт флаг только для специально собранного состояния кота и наблюдателя. Условие можно прочитать в декомпилированном Java-коде, а само значение флага восстановить офлайн из зашифрованного массива. Категория: mobile/reverse; сложность средняя; инструменты: JADX и Python 3.

## Solution

### Разведка

В папке задачи уже лежит декомпиляция APK: `jadx-output/sources/ru/ctf/meowsim/`. APK здесь не запускаем; достаточно читать полученный Java-код.

```bash
rg -n 'canOpenFlagVault|ENCRYPTED_FLAG|deriveKey|stream|DEFAULT_TOKEN|sealFor' jadx-output/sources/ru/ctf/meowsim
```

`rg -n` ищет строки и добавляет номера строк. Важные находки:

```text
QuantumState.java:18: catAlive && catDead && superposition && stability >= 90 && !observed && !tampered
ObserverStore.java:8: DEFAULT_TOKEN = <значение задаётся в исходнике>
FlagVault.java:11: ENCRYPTED_FLAG = {...}
FlagVault.java:38: SHA-256 от полей состояния и суффикса meowsim-v1
```

`[иллюстрация ключевых совпадений; значение константы намеренно не цитируется]`

Первое на вид невозможное условие `catAlive && catDead` становится выполнимым потому, что значения берутся из разных хранилищ: живость питомца и состояние коробки независимы.

### Декодирование

`QuantumState.canOpenFlagVault()` задаёт все требования к состоянию. `BoxStore.sealFor()` показывает формат контрольной печати: `box|<dead>|<superposition>|<stability>|meowsim-v1`. `FlagVault.deriveKey()` соединяет токен наблюдателя, эту печать, стабильность и четыре булевых значения, затем считает SHA-256. Декодер считывает токен из `ObserverStore.java`, а райтап не дублирует его значение.

Флаг — XOR шифротекста с потоком SHA-256. Поток строится как последовательность `SHA256(key || counter)`, где счётчик записан четырьмя байтами в big-endian порядке. Допустимы значения стабильности от 90 до 100; перебор этого небольшого диапазона безопасен и проверяется префиксом `ctfcup{`.

```bash
python3 work/solve_flag.py
```

Скрипт читает сохранённые исходники, проверяет допустимую стабильность и печатает только кандидата с нужным префиксом.

```text
stability=92
ctfcup{cat_0bserv3r_92}
```

`[запущено у меня: 1 ноября 2026]`

### Почему это работает

SHA-256 здесь не взламывается. Приложение само использует его как детерминированную функцию получения ключа и расширения короткого ключа в байты потока. Секретность рушится не из-за свойства SHA-256, а потому что все входы формулы, включая зашифрованный массив, лежат в APK. XOR обратим: если `C = P XOR S`, то `P = C XOR S`.

### Проверка и границы

Декодер повторно получил строку в формате флага; подходящая стабильность — 92. Историческая запись состояния турнира отмечает задачу решённой. Повторную установку APK на Android и нажатия в интерфейсе в этой проверке не выполняли: для восстановления флага они не требуются.

Термины: **декомпиляция** — восстановление читаемого приближения исходного кода из приложения; **XOR** — побитовое исключающее ИЛИ; **big-endian** — запись старшего байта числа первым.
