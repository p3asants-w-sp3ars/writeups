# Receipt

## Условие

Термопринтер печатал с помарками, но чеки продолжали проходить сканер. Найти сообщение в сохранённом чеке.

## Summary

QR-код читается `zbarimg` как URL `https://check.norlanmarket.example/r?...`. Формат QR — version 10, EC-H, mask 3. Изображение содержит намеренно искажённые кодовые слова, но QR остаётся валидным благодаря Reed–Solomon.

## Solution

### Шаг 1: извлечь различия исправленных байтов

QR-код исправляет повреждения кодом Reed–Solomon. Скрипт снимает маску, разделяет поток на восемь блоков, находит исправленные позиции и собирает изменения в исходном порядке чередования. Эти изменения содержат флаг.

Вложения: [receipt.png](files/receipt.png). Сохраните приведённый код как `solve.py` рядом с изображением. Нужны Python 3, Pillow, qrcode и reedsolo.

```bash
python3 -m venv .venv
.venv/bin/pip install 'qrcode[pil]' reedsolo
.venv/bin/python solve.py
```

```python
"""Recover the bytes changed in a QR code while preserving its valid payload."""
from PIL import Image
from qrcode.base import rs_blocks
from qrcode.constants import ERROR_CORRECT_H
from reedsolo import RSCodec

N=57
img=Image.open('receipt.png').convert('1')
# QR v10, EC-H, format mask 3. Function modules are generated by qrcode.
import qrcode
q=qrcode.QRCode(version=10,error_correction=ERROR_CORRECT_H,mask_pattern=3)
q.modules_count=N; q.modules=[[None]*N for _ in range(N)]
q.setup_position_probe_pattern(0,0); q.setup_position_probe_pattern(50,0); q.setup_position_probe_pattern(0,50)
q.setup_position_adjust_pattern(); q.setup_timing_pattern(); q.setup_type_info(False,3); q.setup_type_number(False)

def bits():
    out=[]; row=56; inc=-1
    for col in range(56,0,-2):
        if col <= 6: col -= 1
        while True:
            for c in (col,col-1):
                if q.modules[row][c] is None:
                    # unmask pattern 3: (row+col)%3 == 0
                    out.append((img.getpixel(((c+4)*8+4,(row+4)*8+4)) == 0) ^ ((row+c)%3 == 0))
            row += inc
            if row < 0 or row >= N:
                row -= inc; inc = -inc; break
    return bytes(sum(int(out[i+j]) << (7-j) for j in range(8)) for i in range(0,2768,8))
raw=bits(); blocks=rs_blocks(10,ERROR_CORRECT_H); chunks=[bytearray() for _ in blocks]; p=0
for i in range(max(x.data_count for x in blocks)):
    for j,b in enumerate(blocks):
        if i < b.data_count: chunks[j].append(raw[p]); p += 1
for _ in range(28):
    for c in chunks: c.append(raw[p]); p += 1
errors=[]
for c in chunks:
    _, corrected, positions=RSCodec(28).decode(c)
    errors.append({i: c[i] ^ corrected[i] for i in positions})
ordered=[]
for i in range(max(b.data_count for b in blocks)):
    for j,b in enumerate(blocks):
        if i < b.data_count and i in errors[j]: ordered.append(errors[j][i])
for i in range(28):
    for j,b in enumerate(blocks):
        pos=b.data_count+i
        if pos in errors[j]: ordered.append(errors[j][pos])
flag=bytes(ordered)
print(flag.decode())
open('flag.txt','wb').write(flag+b'\n')
```

Сохранённый вывод:

```text
flag{S1l3nt_C0rr3ct10n_Ch@nn3l}
```
