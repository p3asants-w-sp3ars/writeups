# Uralmash

## Условие

«Бумага помнит обе стороны. Дальше сравни то, что кажется одинаковым». Вложение: [list.png](files/list.png).

## Summary

Младший бит прозрачности PNG раскрывает пароль вложенного ZIP. Внутри изображение с переставленными битовыми блоками и зашифрованным контейнером.

## Solution

PNG содержит ZIP после IEND. Младший бит alpha показывает таблицу символов и граф переходов. По графу цепь от узла 6 даёт trace `B498996846FB6F35CFDD`; цикл даёт слово `pO57YMk4jS`. Пароль архива вычисляется как SHA-256 UTF-8 от строки `B498996846FB6F35CFDDpO57YMk4jS`:

`e561e71bcfc5d72b721fd20a41310a8598f2501295f0da3a4a3cf06967f34b2a`

### Шаг 1: открыть вложенный архив

Нужен 7-Zip. Поместите [list.png](files/list.png) в рабочий каталог и извлеките архив:

```bash
7z x -pe561e71bcfc5d72b721fd20a41310a8598f2501295f0da3a4a3cf06967f34b2a list.png
```

Извлечены `portrait.png` и `instruct.txt`. В instruct описано извлечение 64 блоков 8×8 с последующей перестановкой по шестибитным номерам, затем контейнер `SG2 + u32 BE`, AES-256-GCM; ключ — SHA-256 пароля архива.

### Шаг 2: прочитать скрытые блоки

Номера блоков извлекаются из `XOR(R,G)` LSB (смещение
`(10,1)`, шаг 10), полезная нагрузка — из `XOR(G,B)` LSB (смещение 4, шаг 8).
После сортировки физических блоков по номерам, AES-GCM и zlib получается:

```text
flag{ur4l_p3lm3n_zXc}
```
