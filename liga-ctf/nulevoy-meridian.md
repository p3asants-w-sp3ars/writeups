# Нулевой меридиан

## Условие

В `sexta.dat` лежат две таблицы лимбов, 16 испытаний прибора «Секста» и зашифрованная капсула. В каждом испытании известны восемь начальных ламп и шесть из восьми показаний разъёма. Нужно восстановить порядок вахт, семь поворотов каждой и перестановку выходов. Формат ленты и правила поворота описаны в `protocol.txt`.

## Summary

Каждый поворот аффинен над `GF(251)`. По испытаниям восстанавливаем отображение от ламп к разъёму и делим поиск журнала на две вахты. Печать передачи отсекает почти все варианты первой вахты.

## Solution

### Восстановить строки разъёма

Одно показание даёт уравнение по восьми начальным лампам и свободному члену. Для каждого канала берём только записи, где он считан по маске, и решаем систему из девяти неизвестных методом Гаусса. Получаем восемь строк матрицы `C` в порядке каналов разъёма.

### Сопоставить две вахты

Пусть `A` и `B` — аффинные преобразования первой и второй вахт, а `W` переставляет выходы. Тогда `C = W ∘ B ∘ A`, откуда `C ∘ A⁻¹ = W ∘ B`. Для каждого порядка вахт перебираем `8⁷` журналов первой. Оставляем те, где сумма ламп эталонного прогона после седьмого поворота равна `112 mod 251`.

Индексируем оставшиеся `C ∘ A⁻¹` по первой строке. Для каждого журнала второй вахты ищем эту строку среди восьми строк `B` и сверяем весь набор строк. Позиции совпавших строк дают проводку `W`.

### Открыть капсулу

Проигрываем найденный журнал на всех 16 испытаниях. Для AES-256-GCM хешируем SHA-256 от префикса `SEXTA/handover/3\0`, эталонного старта и полного физического конца, байта порядка, индексов двух вахт и состояний после всех 14 поворотов. Тег GCM подтверждает ключ.

Из каталога `liga-ctf` запускаем [скрипт](solvers/nulevoy-meridian.py) на оригинальной ленте. Нужны Python 3.10+, `cryptography` и компилятор C++17 для [перебора журналов](solvers/nulevoy-meridian.cpp).

```bash
python3 solvers/nulevoy-meridian.py sexta.dat
```

В сохранённом прогоне первой шла утренняя вахта `[4, 2, 5, 0, 4, 1, 6]`, второй — ночная `[5, 0, 5, 2, 6, 0, 5]`. Проводка от канала к лампе `[0, 7, 2, 6, 1, 4, 3, 5]`. Печать совпала, все 16 испытаний сошлись.
